# OF-SABRE-Project
This repository contains Python scripts and Jupyter notebooks that were used in
the SABRE project analysing oscillating polarisation transfer fields.

All the scripts were run on a Windows 11 laptop with an 11th gen. i5 processor
and 16 GB of RAM. The following versions of the software were used when running
the scripts:

- Python: 3.11.9
- Spinguin: v0.0.1
- NumPy: v2.2.3
- SciPy: v1.15.2
- Matploblib: v3.10.1
- SymPy: v1.13.3
- Tqdm: 4.67.1
- Nmrglue: v0.11
